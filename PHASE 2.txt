## Video Generation — Be Honest With Yourself Here

This is the part I need to push back on directly.

A **30-second coherent POV walkthrough of a house from 4 images** is not achievable with reliable quality today, from anyone — not you, not a team ten times your size. Here's why, technically:

Every current video generation model — Runway, Kling, Luma, Pika — struggles to maintain spatial consistency past roughly 5-10 seconds. A "walkthrough" implies the camera moves through connected rooms while everything stays geometrically consistent — walls stay where they are, furniture doesn't morph, the space feels real. That's not a prompt engineering problem, it's a fundamental limitation of how these models work right now. Even Google's most advanced closed models (Veo) aren't there yet for genuine architectural walkthrough consistency, and those aren't publicly available via API for you to use anyway.

What you'd actually get from Runway or Kling with 4 room images: short, disconnected clips with camera pans or zooms — not a real walkthrough. Each generation also costs real money per second of output, and you'd need to generate many attempts to get one usable result. For a two-person bootstrapped team, this is a fast way to burn cash on a feature that will underdeliver against the "wow" your friend is imagining.

**My honest recommendation: don't build the video feature now.** Revisit it in 12-18 months when the underlying models mature. This isn't pessimism, it's just where the technology genuinely is today.

## Technical Honesty on Feature A — Multi-Furniture in One Photo

This is harder than what you built so far, but doable. Two real approaches:

**Approach 1 — Sequential** (simpler, works with what you have): user selects sofa, rug, lamp from catalog → backend runs IP-Adapter replacement three times in sequence, each pass building on the last result. Simple to build, but quality can degrade slightly with each pass.

**Approach 2 — Simultaneous** (better quality, more complex): all furniture gets placed in one generation pass using multiple IP-Adapter reference images at once. Diffusers supports this but it's more involved to get right.

**Generating 3-4 variations** is the easy part regardless of approach — just run the same generation multiple times with different random seeds, return all results, let user pick. An hour of work.

### 1. `roomia-ai-backend/models/render.py`

```python
from __future__ import annotations
import torch
from PIL import Image


def _resize_for_sd(image: Image.Image, max_dim: int = 768) -> tuple[Image.Image, tuple[int, int]]:
    orig = image.size
    w, h = orig
    scale = max_dim / max(w, h)
    if scale < 1:
        w, h = int(w * scale), int(h * scale)
    w = max(8, (w // 8) * 8)
    h = max(8, (h // 8) * 8)
    return image.resize((w, h), Image.LANCZOS), orig


class PhotoRealisticRenderModel:
    def __init__(self):
        self.pipe = None
        self._loaded = False

    def _load(self):
        if self._loaded:
            return
        from diffusers import StableDiffusionImg2ImgPipeline
        print("Loading SD Img2Img (photorealistic render)... first run ~2-3 min")
        self.pipe = StableDiffusionImg2ImgPipeline.from_pretrained(
            "runwayml/stable-diffusion-v1-5",
            torch_dtype=torch.float16,
            safety_checker=None,
        ).to("cuda")
        self.pipe.enable_attention_slicing()
        self._loaded = True
        print("Img2Img ready")

    def render(
        self,
        image: Image.Image,
        prompt: str,
        negative_prompt: str,
        strength: float = 0.42,
        steps: int = 30,
        guidance: float = 7.5,
    ) -> Image.Image:
        self._load()
        img, orig_size = _resize_for_sd(image.convert("RGB"))

        with torch.autocast("cuda", dtype=torch.float16):
            result = self.pipe(
                prompt=prompt,
                negative_prompt=negative_prompt,
                image=img,
                strength=strength,
                num_inference_steps=steps,
                guidance_scale=guidance,
            ).images[0]

        return result.resize(orig_size, Image.LANCZOS)
```

Note: `strength` controls how much it changes the original — 0.42 keeps your furniture layout and composition intact while transforming the render style to photorealistic. Lower = closer to original, higher = more creative freedom.

### 2. Add to `roomia-ai-backend/models/prompt_builder.py`

```python
def build_render_prompt(floor_material: str = "", wall_color: str = "", room_type: str = "") -> tuple[str, str]:
    parts = [
        "professional real estate interior photography",
        f"{room_type} interior" if room_type else "interior room",
    ]
    if floor_material:
        parts.append(f"{floor_material} flooring")
    parts.append(
        "realistic materials and textures, natural lighting, soft shadows, "
        "high dynamic range, architectural photography, photorealistic, sharp focus"
    )
    positive = ", ".join(parts)
    negative = (
        "cartoon, 3d render, video game, low poly, flat colors, unrealistic, "
        "blurry, distorted, watermark, text, people, humans, deformed"
    )
    return positive, negative
```

```python
_render = None

def render_model():
    global _render
    if _render is None:
        from models.render import PhotoRealisticRenderModel
        _render = PhotoRealisticRenderModel()
    return _render


class RenderReq(BaseModel):
    image_base64:   str
    floor_material: str = ""
    wall_color:     str = ""
    room_type:      str = ""
    strength:        float = 0.42


@app.post("/render/photorealistic")
async def render_photorealistic(req: RenderReq):
    try:
        from models.prompt_builder import build_render_prompt
        image = b64_to_pil(req.image_base64)
        prompt, negative = build_render_prompt(req.floor_material, req.wall_color, req.room_type)
        result = render_model().render(image, prompt, negative, strength=req.strength)
        return {"result_base64": pil_to_b64(result, "JPEG")}
    except Exception as e:
        raise HTTPException(500, str(e))
```

### 6. `app/studio/components/RenderPanel.tsx` — new file

```tsx
'use client'

import { useState } from 'react'
import { useStudioStore } from '@/store/useStudioStore'
import { FLOOR_MATERIALS } from '@/lib/studio-constants'

const AI_URL = process.env.NEXT_PUBLIC_AI_BACKEND_URL ?? 'http://localhost:8000'

export default function RenderPanel() {
  const { renderPanelOpen, setRenderPanelOpen, canvasRef, room, activeRoom } = useStudioStore()
  const [stage, setStage] = useState<'idle' | 'rendering' | 'done' | 'error'>('idle')
  const [beforeSrc, setBeforeSrc] = useState('')
  const [afterSrc, setAfterSrc]   = useState('')
  const [error, setError]         = useState<string | null>(null)

  if (!renderPanelOpen) return null

  async function handleRender() {
    if (!canvasRef) {
      setError('Could not capture the 3D view. Try reopening the panel.')
      setStage('error')
      return
    }
    setStage('rendering')
    setError(null)

    try {
      const dataUrl = canvasRef.toDataURL('image/jpeg', 0.92)
      setBeforeSrc(dataUrl)

      const res = await fetch(`${AI_URL}/render/photorealistic`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          image_base64:   dataUrl.split(',')[1],
          floor_material: FLOOR_MATERIALS[room.floorMaterial]?.label ?? '',
          wall_color:     room.wallColor,
          room_type:      activeRoom,
          strength:       0.42,
        }),
      })

      if (!res.ok) {
        const err = await res.json().catch(() => ({}))
        throw new Error(err.detail ?? `Backend error ${res.status}`)
      }

      const data = await res.json()
      setAfterSrc(`data:image/jpeg;base64,${data.result_base64}`)
      setStage('done')
    } catch (err: any) {
      setError(
        err.message.includes('fetch')
          ? 'Could not reach AI backend. Make sure it is running on port 8000.'
          : err.message
      )
      setStage('error')
    }
  }

  function close() {
    setRenderPanelOpen(false)
    setStage('idle')
    setBeforeSrc('')
    setAfterSrc('')
    setError(null)
  }

  return (
    <div className="fixed inset-0 bg-black/70 backdrop-blur-sm z-50
                    flex items-center justify-center p-4" onClick={close}>
      <div className="bg-zinc-900 border border-zinc-700 rounded-2xl w-full max-w-2xl
                      max-h-[90vh] overflow-y-auto p-6 space-y-5"
           onClick={e => e.stopPropagation()}>

        <div className="flex items-center justify-between">
          <div>
            <h2 className="font-bold text-white">Photorealistic Render</h2>
            <p className="text-xs text-zinc-500 mt-0.5">
              Turn your 3D design into a realistic photo
            </p>
          </div>
          <button onClick={close} className="text-zinc-500 hover:text-white text-xl leading-none">×</button>
        </div>

        {error && (
          <div className="bg-red-900/30 border border-red-700/50 rounded-xl px-4 py-3 text-sm text-red-300">
            {error}
          </div>
        )}

        {stage === 'idle' && (
          <div className="space-y-4">
            <p className="text-sm text-zinc-400 leading-relaxed">
              We'll capture your current room view and generate a photorealistic
              version — realistic materials, lighting, and textures based on
              your floor and wall choices.
            </p>
            <button onClick={handleRender}
              className="w-full py-3 bg-amber-400 text-zinc-950 rounded-xl
                         text-sm font-bold hover:bg-amber-300 transition-colors">
              ✨ Generate Photorealistic Render
            </button>
          </div>
        )}

        {stage === 'rendering' && (
          <div className="space-y-4">
            {beforeSrc && (
              <img src={beforeSrc} alt="Capturing" className="w-full rounded-xl border border-zinc-800 opacity-50" />
            )}
            <div className="flex items-center justify-center gap-3 py-4">
              <span className="w-6 h-6 border-2 border-amber-400 border-t-transparent rounded-full animate-spin" />
              <span className="text-sm text-amber-400">
                Rendering... (20–40 seconds, longer on first run)
              </span>
            </div>
          </div>
        )}

        {stage === 'done' && (
          <div className="space-y-4">
            <div className="grid grid-cols-2 gap-3">
              <div>
                <p className="text-xs text-zinc-500 mb-1.5">3D View</p>
                <img src={beforeSrc} alt="Before" className="w-full rounded-xl border border-zinc-800" />
              </div>
              <div>
                <p className="text-xs text-zinc-500 mb-1.5">Photorealistic</p>
                <img src={afterSrc} alt="After" className="w-full rounded-xl border border-amber-400/50" />
              </div>
            </div>
            <div className="flex gap-3">
              <a href={afterSrc} download="roomia-render.jpg"
                className="flex-1 text-center py-2.5 bg-amber-400 text-zinc-950
                           rounded-xl text-sm font-bold hover:bg-amber-300 transition-colors">
                ⬇ Download
              </a>
              <button onClick={handleRender}
                className="flex-1 py-2.5 border border-zinc-700 rounded-xl text-sm
                           text-zinc-300 hover:border-amber-400 hover:text-amber-400 transition-colors">
                🔄 Try Again
              </button>
            </div>
          </div>
        )}

        {stage === 'error' && (
          <button onClick={handleRender}
            className="w-full py-3 bg-amber-400 text-zinc-950 rounded-xl
                       text-sm font-bold hover:bg-amber-300 transition-colors">
            Try Again
          </button>
        )}
      </div>
    </div>
  )
}
```
