OVERALL FLOW — WHAT WORKS
-------------------------
Landing → Configure (3 steps) → Result → Plan / 3D

✓ Configure is clear and fast (room → style → budget)
✓ Result page is the right hub: furniture, budget, email, WhatsApp, viz links
✓ Room scanner on step 1 is a nice differentiator
✓ Email capture + share links work

Main flow gap: 2D floor plan and 3D room do NOT talk to each other.
User arranges furniture in 2D, opens 3D, gets a completely different layout.
This is the biggest user-facing bug right now.


2D FLOOR PLAN — CURRENT STATE
-----------------------------
File: app/plan/FloorPlanCanvas.tsx

What works:
  - Drag-and-drop with wall bounds
  - 1m grid + dimension labels
  - Responsive width (ResizeObserver)
  - Category colors match 3D

What's weak:
  - Grid-stacks from corner (old 3D bug — still here in 2D)
  - 2D layout ≠ 3D layout (user rearranges in 2D, 3D ignores it)
  - Positions lost on refresh (drag work disappears)
  - No rotation (can't turn sofa to face wall)
  - No overlap warning (pieces can stack on each other)
  - No save / export (can't screenshot or share arrangement)
  - Dark theme on plan page, light on result — feels like two apps


3D ROOM VIEW — CURRENT STATE
------------------------------
File: app/room3d/Room3DCanvas.tsx

What improved (recent fix):
  - Smart category-based placement (sofa back wall, table in front, etc.)
  - Floor-snapping for GLB models (yOffset on position prop)
  - Box fallbacks while models load
  - Light gets pole + sphere instead of flat cube

What's still weak:
  - Ignores 2D drag positions
  - Placeholder GLBs (bed/light = Couch Medium, etc.)
  - GLB models have no name labels (only box fallbacks show names)
  - No rotation on models
  - Fixed 560px canvas height (cramped on mobile)
  - Large rooms (12×6m) feel empty with only 5 pieces
  - Outdated footer: "Real 3D models coming with partner catalog"
  - No per-model error boundary (one bad GLB can crash scene)
