ROOMIA — HOSTED SAM2 (live Composer)

Date: 20 September 2026

Public Composer needs a click-mask. GPT Image still runs in the cloud.
SAM2 used to mean “this PC + Cloudflare tunnel”. That dies when the
machine sleeps. For a pitch, host SAM2.

Preferred: Replicate  https://replicate.com/meta/sam-2
Fallback:  this GPU + tunnel (below)


================================================================================
A. REPLICATE  (always on — use this for a client presentation)
================================================================================

Their model is automatic (“segment everything”), not a click.
Roomia runs it once per photo, then picks the smallest mask under the pin
(sofa, not the whole room). Extra pins on the same photo are free.

1. Create a token: https://replicate.com/account/api-tokens
   (~$0.02 / photo, ~19s)

2. Local:

     echo 'REPLICATE_API_TOKEN=r8_…' >> .env.local

3. Live (Vercel, production + preview):

     npx vercel env add REPLICATE_API_TOKEN production preview --sensitive
     # paste the token, then Redeploy

   Server-side only. Never NEXT_PUBLIC_*.

4. After deploy, Composer on https://www.room-ia.com/room-composer
   does not need this PC.

Smoke (local Next running):

     curl -sS -X POST http://localhost:3000/api/segment \
       -H 'Content-Type: application/json' \
       -d '{"image_base64":"<jpg-or-png-base64>","x":0.5,"y":0.5}'


================================================================================
B. THIS GPU + TUNNEL  (only if Replicate token is unset)
================================================================================

The live site cannot see localhost:8000. Tunnel the FastAPI SAM2.

  1. This machine ON, not sleeping
  2. Backend:   npm run back     (from roomia, port 8000)
  3. Tunnel:    cloudflared tunnel --url http://127.0.0.1:8000
  4. Vercel AI_BACKEND_URL = the trycloudflare URL
  5. Vercel AI_BACKEND_SECRET = same as roomia-ai-backend/.env
     (header x-roomia-ai-key)

If you reboot or restart the tunnel, the trycloudflare hostname CHANGES.
Update Vercel AI_BACKEND_URL and Redeploy.

Named tunnel + ai.room-ia.com later = stable hostname (needs Cloudflare login).

Warm once:

  curl -sS -H "x-roomia-ai-key: YOUR_SECRET" https://something.trycloudflare.com/warmup


================================================================================
SECURITY
================================================================================

REPLICATE_API_TOKEN and AI_BACKEND_SECRET stay server-side.
Do not put them in git or NEXT_PUBLIC_*.
The trycloudflare URL is on the public internet — keep AI_BACKEND_SECRET on.


================================================================================
IF COMPOSER FAILS LIVE
================================================================================

"SAM2 is not hosted" / REPLICATE_API_TOKEN
  → token missing on Vercel, or deploy older than the Replicate wire

"Could not reach SAM2"
  → token unset AND (backend/tunnel down, or AI_BACKEND_URL stale)

401 Unauthorized
  → Vercel AI_BACKEND_SECRET ≠ backend AI_BACKEND_SECRET

Kitchen full-frame restyle does not need SAM2.
Studio photoreal does not need SAM2 (GPT Image only).
