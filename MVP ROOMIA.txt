2/Configurator — Full Step-by-Step Flow:

Step 1 — Room Info
• Room type: Living Room / Bedroom / Kitchen / Office / Full Apartment
• Shape: Simple (rectangle) → user enters Width × Length in metres
• Shape: Complex → user uploads floor plan photo → AI (Claude Vision API)
• reads it, extracts dimensions, generates a simplified plan SVG
• That's it. No apartment type (F2/F3). Room size + shape is all that matters.

Step 2 — Style Picker
• Show 4–5 large visual cards, each with a curated moodboard image (your GF selects these)
• Styles at launch: Modern · Minimal · Warm & Cozy · Traditional Algerian · Industrial
• Each card: style name + 3-word tagline (e.g. 'Clean. Light. Open.')
• User picks ONE. This is the most visually critical step — images must be beautiful.

Step 3 — Budget Range
• 3 options only — no free input (people don't know exact budgets)
• Tight / Comfortable / Premium
• DZD ranges defined by your GF based on real Algerian market prices
• Example: Tight < 150,000 DZD · Comfortable 150k–400k · Premium 400k+
Step 4 — Priorities (quick, 2 picks max)

• Comfort · Aesthetics · Storage · Durability · Price
• This feeds the furniture ranking logic — makes the result feel personalised
• Cheap to build, high perceived value for the user

5/Tech Stack Recommendation:
-Frontend — Next.js (not Vue)
You know React. Vue is fine, but Next.js gives you SSR (critical for SEO — people searching 'interior design
algeria'), built-in API routes (you might not even need a separate backend for MVP), file-based routing, and it
deploys to Vercel in one click. It's also the industry standard right now. When you go mobile with Capacitor later,
you can wrap the Next.js app just as easily as Vue.

-Backend — Do you even need Laravel for MVP?

Honest answer: probably not at first. Supabase gives you a Postgres database, auth (if you need it later), file
storage for images, and a real-time API — all for free at MVP scale. Your Next.js API routes handle the logic.
Laravel becomes relevant when you build the partner dashboard, commission tracking, and CMS for your GF to
update furniture content. Add it in Phase 2. For now: Next.js + Supabase = you ship faster.

7/AI Room Scan — How It Works:

When the user says their room is an irregular shape, they upload a floor plan photo (hand-drawn, printed, or
screenshot). Here's the flow:
1. User uploads photo in Step 1 of the configurator
2. Frontend sends image to your Next.js API route as base64
3. API route calls Claude Vision API with prompt:
"Analyze this floor plan. Extract the room dimensions if visible.
Return a JSON: { width_m, length_m, shape_type, notes }"
4. Claude returns the parsed dimensions
5. You display a simple SVG rectangle/polygon preview to confirm
6. User confirms or adjusts — then continues to Step 2
Cost: Claude API calls are fractions of a cent each. For MVP volume, this is essentially free.
